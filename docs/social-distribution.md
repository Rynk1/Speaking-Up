# Social Distribution Engine (SSDE) & Dynamic OpenGraph Specification

## 1. Dynamic OpenGraph SSR Preview Middleware
When post URLs (`/post/:id` or `/s/:code`) are shared on WhatsApp, X, Facebook, or Telegram, crawler user-agents receive dynamically rendered OpenGraph HTML tags containing:
* Sanitized P³RE title and summary.
* Safe regional location string.
* Number of verified citizen witness confirmations.
* Direct public projection image preview.

## 2. Multi-Platform Adapters
Platform capabilities registry (`PlatformCapabilityRegistry.ts`) formats tailored copy and media constraints for WhatsApp, TikTok, Instagram Reels, YouTube Shorts, X, and Facebook.
